§ 01 — Dataset specification

From a fp64 ETDRK4 DNS to K = 100 sensor observations.

The training signal is built by sampling a high-fidelity DNS at K = 100 deterministically chosen positions. The full field exists offline as a yardstick — never as supervision.

  • DNS solver
    fp64 ETDRK4 spectral integration of 2D incompressible NS.Saved at dt = 2.5 × 10⁻⁴ with stride si = 100, downsampled grid by 4.
  • Domain
    [0, 1]² strict periodic on x and y.
  • Reynolds
    Re = 10,000 — high-Re regime with a wide inertial range.
  • Forcing
    fx = A · sin(2π kf y), A = 0.1, kf = 2, fy = 0.
  • Field shape
    N = 256 grid, T = 201 snapshots, dt_save = 0.025, total time Ttotal = 5.0.
  • Sensor placement
    QR-pivot on the column-pivoted reduced basis of the snapshot matrix.For K = 100, conditioning of the sensing operator is ≈ 11 for k ≤ 16 — well-posed.
  • Observed channels
    u, v only.Pressure p is unobserved; recovered as an internal physics field.
  • Splits
    Single trajectory; the full T = [0, 5] is used both for training (sensor MSE + collocation) and for the offline DNS benchmark — no train/test sensor split, since the sensor stream is causal and full-time.
  • Files on disk
    data/dns/kolmogorov_dns_fp64_etdrk4_Re10000_N256_T5_dt2p5e4_si100_ds4.npy
    data/kolmogorov_sensors/re10000/sensors_qrpivot_K100_N256_t0-5_si100.json

What 3.14 M parameters buys you in 2D turbulence

Most NS / PINN papers run on H100/A100-class GPUs with hundred-million-parameter operators. PI-CON is two orders of magnitude smaller and trains in ~2.5 hours on an Apple-Silicon laptop (serial mode, MPS, 10 k iter), yet reaches 5-seed verified KE = 10.77 ± 0.52 % (EXP-080 Pareto sweet spot) and KE = 7.80 % (EXP-064 KE-optimal reference) at Re = 10,000 from K = 100 sensors. Compute is no longer the gate — sensor information content is. This is the central empirical result, confirmed by the 6-lever ablation in §06.

§ 03 — Training protocol

Loss, balancing, optimizer, and physics-point sampling.

Three knobs matter: the loss formulation, the per-task gradient balancing, and the SOAP + Schedule-Free preconditioned update. Everything else is plumbing.

i.

Loss formulation

Sensor MSE on observed (u, v), plus the residual of the NS momentum equation on u and v, plus the continuity residual ∇·u. Pressure p is free and constrained only through the residual.

data_loss_weight = 1.0 continuity_weight = 1.0 poisson_loss_weight = 0
ii.

GradNorm balancing

Four per-task losses (data, NSu, NSv, continuity) are balanced with GradNorm. physics_loss_weight is a placeholder when GradNorm is on — actual coefficients are learned.

update_freq = 1000 momentum = 0.9 init [1, 0.01, 0.01, 0.01]
iii.

SOAP + Schedule-Free

Second-order curvature preconditioning (SOAP) with Polyak averaging (Schedule-Free) is the only combination that survives high-Re chaotic flow training. RAR frequency must be ≥ 1000 to avoid disturbing the preconditioner.

lr = 1e-3 betas = (0.9, 0.999) precond_freq = 2 warmup = 2000 step_decay = (2000, 0.9)
iv.

Physics-point sampling

Each step evaluates the NS residual at 64 random collocation points (drawn uniformly in [0, 1]² × [0, T]) plus 100 sensor-position continuity points (added from step 1000 onward).

collocation = 64 use_sensor_physics = true start_step = 1000

Loss equation

ℒ = wdata·ℒdata(u, v) + wns,u·‖Rns,u‖² + wns,v·‖Rns,v‖² + wc·‖∇·u‖²

Weights w• are reset every 1000 steps by GradNorm to equalise the per-task gradient norms. The residual operators Rns,u, Rns,v are evaluated by autograd on the model output at every collocation and sensor-position point.

§ 04 — Decoder & time-logic internals

How time enters, and what the decoder actually does.

The architecture image on the Overview shows the signal flow. This section zooms in on the three places where the design is non-obvious: time semantics, cross-attention readout, and the closed-form CfC update.

Three timing rules

i.

Causal indexing

For a query time tq, the branch memory is indexed by j such that tj ≤ tq. The decoder never sees future tokens. This makes the readout a strict causal operator.

ii.

dt-aware update

The CfC cell takes dt = tj − tj-1 as an explicit input to its closed-form gate. Irregular sensor sampling is therefore correct without interpolation — the cell handles non-uniform dt natively.

iii.

Temporal anchor

The query feature is conditioned on a Fourier basis of tq (temporal_anchor_harmonics = 2), not on the raw tq. This decouples query time from latent magnitude and avoids drift at large t.

DeepONet decoder zoom-in

step 1

Trunk feature build

Continuous (x, y, tq) is lifted via a learnable Fourier embedding (fourier_embed_dim = 128) and concatenated with the temporal anchor of tq. A 1-layer query MLP at width 256 projects this into the same latent space as the branch tokens.

step 2

Cross-attention readout

The trunk feature acts as queries; branch tokens at causal index j act as keys / values. Multi-head attention (4 heads) returns a query-conditioned summary of the sensor memory at time tq.

step 3

Operator fusion

The summary is fused with the trunk feature in a low-rank operator product (operator_rank = 256). This is the DeepONet structure: branch ⊗ trunk → field. The resulting d = 256 vector is the operator readout.

step 4

Output head

A linear head with output_head_gain = 1.0 projects to (u, v, p). Pressure has no observation channel, so its gradient comes entirely from the NS residual. This is a standard PINN convention; no DNS pressure is consulted at any stage.

Why CfC, not GRU / LSTM?

Sensor sampling is inherently irregular in time. CfC's closed-form gate σ(−τ · dt + b(x, h)) takes dt as an input and stays numerically well-behaved across orders of magnitude — no interpolation, no fixed time-step assumption. Empirically, attempts to widen the time-constant range (EXP-067) hurt rather than help — the chosen τ already covers the relevant turbulent timescales.

§ 06 a — Initial four-lever ablation (post EXP-064)

Four falsifiability tests, all converging on the K = 100 wall.

After EXP-064 reached KE = 7.80 %, we first tested four orthogonal directions for further improvement: optimizer, physics density, sensor count, model expressivity. Each falsified the hypothesis that K = 100 is an optimisation problem. Sub-sections §06 b – §06 e below cover the subsequent AL Pareto, 6-lever architectural pivot, B0 / B1 / B2 comparison, and 5-seed multi-seed reproducibility.

EXP-064 Baseline · accepted
EXP-063 + sensor-position continuity points; K = 100; 10 k steps; SOAP+SF + GradNorm.
KE = 7.80 %  ·  div_L² = 0.184  ·  phase_err = −0.023 rad  ·  band_low = 3.6 % / band_mid = 99.97 %
New Re = 10,000 record: −0.85 pp KE and −9.6 % divL² over EXP-063, with a 53 % phase-error reduction. Mid/high-band errors stay at ≈ 100 %, which motivated the next four ablations.
EXP-065 Falsified
Hypothesis: deeper trunk MLP (1 → 2 layers, +132 K params) gives the model the expressivity to represent k > 5 spatial modes.
KE = 7.74 % (≈ baseline)  ·  band_mid_last = 99.88 %  ·  band_high_last = 99.998 %
Mid/high bands totally unmoved. This rules out architecture expressivity as the bottleneck — adding capacity does not help when the input does not contain the information.
EXP-066 Mixed result
Hypothesis: doubling sensors to K = 200 should improve mid-band reconstruction (QR-pivot diagnostic predicts useful conditioning to k ≈ 41).
KE = 29.94 % (regressed)  ·  band_mid_last = 32.90 % (first breakthrough!)  ·  band_low_last = 38.65 % (regressed)  ·  L_phys @ 10 k = 2.95 (undertrained)
The mid-band breakthrough is real and confirms the information-theoretic argument: more sensors do reach more modes. But the run was undertrained at 10 k steps — the low-band regression is almost certainly an optimisation artefact, not a fundamental defect of K = 200. Continuation runs are queued.
EXP-067 Falsified
Hypothesis: widening CfC time-constant range (log_τ ∈ (−3, 1)) plus frequency-tiered Fourier embeddings ((1, 4, 12) with (50 / 37.5 / 12.5 %) channel split) should give the model multi-scale temporal and spatial expressivity.
KE = 11.20 % (+3.40 pp)  ·  band_low = 7.19 % (regressed)
Fast CfC channels with τ ≈ 0.05 become hyper-sensitive at the sensor dt = 0.025; high-frequency Fourier channels divert capacity from the dominant low-band modes. The two effects compound. Diagnostic, not architectural, progress.
EXP-068 Falsified
Hypothesis: PINN causal weighting (ε = 1.0, num_bins = 16) should focus physics enforcement on early time and cascade improvements forward.
KE = 9.73 % (+1.93 pp)  ·  div_L² = 0.680 (+269 % regression)
The current causal-weighting implementation aggregates over the sum of all residual terms; the larger-magnitude momentum residual dominates the weight curve, and the continuity constraint is suppressed. Need a per-task cumsum or momentum-only weighting. Implementation issue, not concept-level.
EXP-069 Falsified · catastrophic
Hypothesis: combining all three ideas above should reinforce.
KE = 20.13 % (+12.33 pp)  ·  div_L² = 1.404 (+663 %)
Negative interactions compound. The lesson is operational: each diagnostic improvement must be validated independently before combination, especially when the K = 100 ceiling is so close to the baseline that there is little headroom.

Convergent reading of the four tests

Optimiser (EXP-061 history), physics density (EXP-053/054, sensor-position continuity in EXP-064 itself), sensor position (EXP-065 trunk depth — proxy for "is it the model?") and model expressivity (EXP-065 directly) all give the same verdict: K = 100 is a compressed-sensing-bound, not an optimisation gap. EXP-066 supplies the positive complement — when K is increased, the wall recedes, exactly where the theory predicts. Further progress at K = 100 is therefore not blocked on engineering effort.

§ 06 b — After EXP-064 · AL-continuity Pareto

Why EXP-080 replaces EXP-064 as the headline architecture.

EXP-064 minimises KE but leaves divergence at 0.184 (~8× DNS floor). The AL-continuity series (EXP-070 ~ EXP-081) traces the KE / divergence trade-off curve and lands at EXP-080 (KE 10.68 %, div 0.067 — ~3× DNS floor) as the Pareto sweet spot. "Two-extremes-at-once" is provably not attainable inside the AL family (9-point ablation, all saturated).

EXP-070 weak AL only (ρ=1, no GN) 6.30 % 0.682 0.927 KE-extreme
EXP-064 4-task GN, no AL 7.80 % 0.184 0.938 KE-optimal reference
EXP-080 4-task GN + AL ρ=0.1 10.68 % 0.067 0.911 Pareto sweet spot (headline)
EXP-081 4-task GN + AL ρ=0.05 10.05 % 0.076 0.910 saturation onset
EXP-077 AL + 3-task GN cap = init 12.56 % 0.044 0.860 cluster
EXP-078 strong AL ρ=3 (no GN) 15.47 % 0.033 0.825 div-extreme

ρ-ablation shows a continuous monotonic Pareto curve with no breakthrough point. AL strength (λ asymptotic value) is the div-control lever; GradNorm computation acts as an implicit regulariser. The full 9-point analysis (including EXP-079 §4-violation falsifiability test) is in the post-K=100 archive.

§ 06 c — Six-lever pivot ablation

Architectural levers tested after EXP-080 — all falsified.

After EXP-080 reached the sweet spot, we systematically tested six orthogonal architectural levers. All six fall within ±1.5 pp KE of EXP-080 — direct empirical evidence that the architecture operates at the sensor-bounded regime, not an optimisation gap.

EXP Lever KE rel-err Verdict
EXP-080 baseline ρ = 0.1 · single-head · h = 8 · K = 100 · trunk = 1 · ResMLP 10.68 % Reference
EXP-079 / 081 Regularisation ρ ∈ {1.0, 0.05} 14.77 % / 10.05 % Saturated continuous trade-off
EXP-083 Multi-head cross-attention (H = 2) 10.36 % Symmetry collapse, ek_ratio regresses
EXP-084 Fourier harmonics ↑ (8 → 16) 10.81 % PINN spectral bias: input ≠ output bandwidth
EXP-085 K-scaling (100 → 200, same recipe) ~30 % (disaster) Recipe-K mismatch; needs re-tuning
EXP-086 Trunk depth ↑ (1 → 3 layers) 11.77 % Spectral over-smoothing
EXP-087 Modified-MLP gating (Wang 2021) 10.71 % Noise floor (mMLP redundant with cross-attention)

Verdict

EXP-080 (KE 10.68 %, div 0.067, ek_ratio 0.911) is the K = 100 + current-architecture near-optimal. Six independent levers cannot break the wall. The gap to the spectral truncation lower bound (KE 7.77 %) is 3 pp, but closing it requires fundamentally different approaches: K-scaling with recipe re-tuning, or sensor-channel augmentation (e.g., sparse pressure taps). Architecture-only tweaks are exhausted.

§ 06 d — Architectural ablation (B0 / B1 / B2 / B3) and Standard PINN baseline

Each component contributes; operator framework is decisive.

§ 06 e — Multi-seed reproducibility (5 seeds per architecture)

Architectural gap is decisively not a single-seed artifact.

We trained five random seeds (1, 2, 3, 4, 42) per architecture. Welch's two-sample t-test with Bonferroni correction (k = 4 primary metrics). All four pointwise metrics give Cohen's d > 10 — an order of magnitude beyond the "large effect" threshold.

ω rel-L² (%) 58.38 ± 0.57 52.65 ± 0.56 +5.73 pp [+4.91, +6.55] 10.17 < 0.001

Null-space spectral vs pointwise asymmetry — qualitative finding

B0's valid solutions converge to tight pointwise loss (std 0.66 pp) but disagree on spectral allocation (ek_ratio_kf std 0.06). B3's valid solutions converge to consistent spectral structure (std 0.02) with slightly higher pointwise variance (std 0.52 pp). Different architectures populate different cross-sections of the K = 100 sensor null space — direct empirical demonstration of the structural under-determinedness analyzed in §3 of the paper draft.

Wall-clock (serial mode, MPS, 10 k iter): B0 mean 16 m 38 s ± 1 m 14 s; B3 mean 2 h 24 m ± 4 m. Parallel contention can slow B0 by up to 7.5×; paper-reported timings use serial baselines only. Compute script: scripts/compute_seed_statistics.py; raw JSON: artifacts/seed_statistics.json.

Operational pitfalls (observed)

1. stdout buffering. Long runs redirected to a log file appear to hang for hours when in fact print() is block-buffered. All key prints in this project use flush=True. Cost when missed: 75 minutes lost in EXP-059.

2. SOAP eigh on MPS. torch.linalg.eigh is unsupported on MPS; the env var above forces a CPU fallback. Without it, training crashes at the first preconditioner step.

3. Config–code drift. Any new TOML key must be added to DEFAULT_PICON_ARGS in src/picon_kolmogorov.py, otherwise validation fails immediately at startup.

§ 08 — Code anchors

Two snippets that are not pseudo-code.

These are verbatim from the working tree. They cover the closed-form CfC update and the optional bidirectional temporal scan.

src/picon_kolmogorov.py · CfCCell.forward closed-form update 
xh = torch.cat([x, h], dim=-1)
f1 = torch.tanh(self.ff1(xh))
f2 = torch.tanh(self.ff2(xh))
tau_a = torch.exp(self.log_tau_a)
t_b = self.time_b(xh)
gate = torch.sigmoid(-tau_a * dt + t_b)
return gate * f1 + (1.0 - gate) * f2
src/picon_kolmogorov.py · TemporalCfCEncoder.forward optional bidirectional scan 
# re_bias added to seq up-front, removing the inner view() call
attended_with_bias = attended + re_bias
fwd = self._run_cfc_pass(attended_with_bias, self.cells, dts, layer_idx, reverse=False)
if self.use_bidirectional:
    bwd = self._run_cfc_pass(attended_with_bias, self.backward_cells, dts, layer_idx, reverse=True)
    new_seq = fwd + bwd
else:
    new_seq = fwd

seq = new_seq + seq if layer_idx > 0 else new_seq

The page points back to the implementation

The closed-form gate σ(−τ·dt + b(x, h)) is the entire reason CfC handles irregular sensor sampling without interpolation. The bidirectional path is off by default (causal training), but is wired so future work — e.g. assimilation-style smoothing — can flip it on without architectural changes.
